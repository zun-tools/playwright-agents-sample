# 買い物メモ テスト計画

## Application Overview

買い物メモ(http://localhost:8080/)のテスト計画。実在機能は「品物の追加(ボタン/Enter)」「チェックのオン/オフ」「残り件数表示(role=status)」のみ。削除機能・永続化は存在しない(ボタンは「追加」1つのみ、リロードで全消去を確認済み)。既存テスト(tests/shopping.spec.js)の「2品追加→件数2→1品チェックで残り1」は除外。重要度順に5シナリオ。各シナリオは seed 後のまっさらな状態(品物0件、「残り 0 品」)から開始する。

## Test Scenarios

### 1. 買い物メモ

**Seed:** `tests/seed.spec.ts`

#### 1.1. 1. 空・空白のみの入力は追加されない

**File:** `tests/shopping/empty-input.spec.ts`

**Steps:**
  1. (重要度1位: 入力検証の唯一の防御で、壊れると空行が量産されるため) 「品物」欄が空のまま「追加」をクリック
    - expect: リストは0件のまま
    - expect: 「残り 0 品」のまま
  2. 「品物」に半角/全角スペースのみ「   」を入力して「追加」をクリック
    - expect: リストは0件のまま
    - expect: 「残り 0 品」のまま
  3. 「牛乳」を追加した後、再度空のまま「追加」をクリック
    - expect: リストは1件のまま
    - expect: 「残り 1 品」のまま

#### 1.2. 2. チェックを外すと残りが戻り、取り消し線が外れる

**File:** `tests/shopping/uncheck.spec.ts`

**Steps:**
  1. (2位: 既存テストはチェックのみで、解除と見た目(done クラス)が未検証のため) 「牛乳」「卵」を追加し、「牛乳」をチェック
    - expect: 「残り 1 品」
    - expect: 牛乳の li に class done が付く(取り消し線)
  2. 「牛乳」のチェックを外す
    - expect: 「残り 2 品」に戻る
    - expect: li から done クラスが消える
  3. 「卵」もチェックし、全部チェックする
    - expect: 「残り 0 品」(リスト自体は2件のまま)

#### 1.3. 3. Enterキーで追加でき、追加後に入力欄が空になる

**File:** `tests/shopping/enter-key.spec.ts`

**Steps:**
  1. (3位: ボタン以外の主要な追加経路で、フォーム submit 実装に依存するため) 「品物」に「パン」を入力して Enter を押す
    - expect: 「パン」がリストに1件追加される
    - expect: 入力欄が空になる
    - expect: 「残り 1 品」
  2. 続けて「みかん」を入力して「追加」ボタンをクリック
    - expect: リストは2件で追加順(パン、みかん)
    - expect: 「残り 2 品」

#### 1.4. 4. 前後の空白は除去され、同名の重複・長い名前も追加できる

**File:** `tests/shopping/trim-duplicate-long.spec.ts`

**Steps:**
  1. (4位: 入力の正規化と境界値で、仕様確認の意味合いが強いため) 「  牛乳  」(前後に空白)を追加
    - expect: リスト項目のラベルが「牛乳」(前後空白なし)で表示される
  2. 同じ「牛乳」をもう一度追加
    - expect: 重複でも2件になる(現状の観察された挙動)
    - expect: 「残り 2 品」
    - expect: 片方だけチェックすると「残り 1 品」
  3. 200文字の「a」を追加
    - expect: 3件目として追加される
    - expect: 「残り」が正しく加算される

#### 1.5. 5. HTMLを含む入力が文字列として表示される(XSS確認)

**File:** `tests/shopping/html-escape.spec.ts`

**Steps:**
  1. (5位: 発生頻度は低いが、安全性に関わるため) 「<b>x</b>」を追加
    - expect: ラベルに「<b>x</b>」がそのままテキスト表示される
    - expect: 太字の要素は生成されない
    - expect: 「残り 1 品」
  2. 「<img src=x onerror=alert(1)>」を追加
    - expect: ダイアログは表示されない
    - expect: 文字列としてリストに表示される
